About The Project

Thenux Fitness is a production-grade Android fitness application engineered for real athletes and everyday gym-goers alike. Built entirely in Kotlin with a clean MVVM architecture, it runs fully offline — no subscription, no cloud dependency, no ads.

Every feature is crafted with precision: from animated progress rings to multi-profile SQLite storage and a smart notification engine that adapts to your weekly training schedule.

Open source and community-driven — because fitness tools should be built by people who actually use them.

100% Offline
No internet required. All data stays on your device.
Multi-Profile
Manage multiple athlete accounts on one device.
Zero Ads
Clean experience. No trackers, no interruptions.
Open Source
MIT licensed. Fork it. Build on it. Make it yours.

Installation

GET STARTED
IN MINUTES

Install the APK directly or build from source with Android Studio.

terminal
# Clone the repository
git clone https://github.com/thenuxofc/Thenux-Fitness.git
# Enter project directory
cd Thenux-Fitness
# Open in Android Studio
# File → Open → Select folder
# Sync Gradle & run
Shift + F10 # Run on device
REQUIREMENTS
Android Studio Hedgehog 2023.1.1+
JDK 17 or higher
Android SDK 34 · Min SDK 26
Android 8.0 device or emulator
